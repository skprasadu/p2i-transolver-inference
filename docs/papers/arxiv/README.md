# Submission source package — review draft

`main.tex` and the included PNG figures are the LaTeX submission sources.
`main.pdf` is compiled locally with Tectonic and visually inspected.
`manuscript.md` is an intermediate generated from the canonical Markdown report.

Rebuild from the main P2I repository:

```sh
.venv/bin/python tools/release/build_transolver_paper.py
```

The original GPU checkpoint remains tagged separately. The publication follow-up
has a different scope and is not substituted into the old raw evidence files.

- Review the final abstract, contribution, benchmark limits and author name.

- Supply the final public repository URL only after its visibility is approved.
